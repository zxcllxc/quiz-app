# quiz-app

## How to run

1. Clone the repository.
2. Open the project folder.
3. Go into the backend folder:

   ```bash
   cd backend
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the backend:

   ```bash
   npm start
   ```

The server should show:

```text
Server is running on port 3000
```
